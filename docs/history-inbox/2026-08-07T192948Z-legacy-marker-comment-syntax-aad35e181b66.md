## 2026-08-07 旧マーカー検出をコメント構文まで一致させる

`apply-common.mjs` は旧マーカー（`AI-OPS:COMMON`）を**素の部分文字列**で数えて、1つでもあれば
同期を失敗させていた。旧マーカーの自動移行をやめた以上、実物が残っていたら止めるのは正しい
——が、判定が広すぎた。`AGENTS.md` の本文に「旧マーカーは使うな」と**書いただけ**で同じ判定に
かかり、その consumer への配布が止まる。しかも `apply-common.mjs` は全 consumer に対して回る
ので、「マーカーの掃除を促す注意書き」を1つ書いた副作用で配布そのものが落ちる。

判定を `<!-- AI-OPS:COMMON START|END … -->` の骨格を見る正規表現にした。START 側の説明文は
consumer ごとに揺れうるので、そこは `[^>]*` で吸収して**コメントであることと START/END の別**
だけを見る。バッククォートで囲んだ言及・散文中の言及は当たらない。

同時に `shared/docs/ops-sync-design.md` の記述も直した。実装が旧マーカーを一切受け付けなく
なったのに、配布 doc 側は「**新旧どちらか一方**の組が1組なら健全」のままだった。この doc は
consumer に配られるので、読んだ人は移行が走ると期待して、実際にはエラーで止まる。**仕組みを
変えたら同じ PR で配布 doc も直す**（AGENTS.md「完了手順」）を踏み外していた。

回帰テスト `scripts/apply-common.test.mjs` を新設した。「実物の旧マーカーは弾く」と「言及だけは
通す」を対で置いてある——片方だけだと、次に判定を触る人がどちらかへ倒しても気づけない。
