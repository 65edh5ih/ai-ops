## 2026-08-03 課金判定は全ジョブ・matrix 展開後まで見る

指摘の範囲を読み違えて**部分的にしか直さなかった**分の追加。元の指摘は「全ジョブ、reusable workflow、
matrix 展開後の `runs-on` まで辿る」で、こちらが足したのは `workflow_call` の分だけだった。resolve すると
返信した後に範囲不足に気づいたので、訂正を投稿して残りを別 PR にしている。**指摘の要求範囲を数えてから
直す**（要素が3つ並んでいたら3つとも潰す）。

内容として要るのは次の2点:

- **run で走りうる全ジョブを見る**。1ジョブだけ見て「無料」と判断できない——1つでもコストを伴うジョブが
  あればその run にはコストがある。

  ジョブ定義を読んだだけでは larger runner が混ざっていても気づけない。

印の文言（月枠を消費する／実行のたびに課金される）はこの判定の結果で決まるので、**見る場所を間違えると
文言が逆になる**。ここが「読めば分かる」ではなく手順として書く価値のある所。
