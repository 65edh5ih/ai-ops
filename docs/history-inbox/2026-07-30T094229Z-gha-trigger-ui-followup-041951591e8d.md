## 2026-07-30 Actions 起動ボタン規約の consumer 同期 PR 指摘を正本で修正

前段の PR（#130）に対する Codex の指摘は、**ops-sync 本体の PR には出ず、マージ後の consumer 同期 PR に
だけ**3件出た。AGENTS.md「配布変更のダウンストリーム確認」が想定しているとおりの現れ方で、購読していな
ければ全 consumer に欠陥が残っていた。3件とも `shared/` 正本で直して再配布する（consumer 同期 PR は手編集
しない）。

**枠消費の条件を可視性ではなく課金対象かで書き直した**のが一番効く修正。前段では「private なら消費・public
なら無料」と書いたが、これは**セルフホストランナー（private でも枠を消費しない）と larger runner（public でも
課金される）で破れる**。UI の文言が実態と食い違うと、印そのものが信用されなくなって規約が形骸化するので、
判断材料を `runs-on` に置き換えた。前段で「public に枠消費の文言を書くな」を MUST NOT にしていたため、
セルフホスト構成では逆に**必要な警告を禁止してしまう**穴もあった。

skill ラッパーの `description` にも枠消費の断定が残っていた。**description は発火トリガであると同時に、
doc を開く前にエージェントが読む唯一の文**なので、本体と食い違うと本体を読まずに誤った文言を書く経路になる。
本体を直したら description も揃える（同じ文が7つのミラーに複製されるので、正本1箇所で直す）。

sibling doc へのリンクは `docs/<name>.md` ではなく `<name>.md` で書く。参照の**表記**を consumer パスに
揃える規約（AGENTS.md）と、**リンク先**が相対解決される事実は別問題で、前者に引きずられて
`](docs/actions-quota.md)` と書くと GitHub 上で `docs/docs/...` の 404 になる。既存の `net-fetch.md` が
「ラベルは `docs/actions-quota.md`・リンク先は `actions-quota.md`」の正しい形をとっていたので、それに合わせた。
